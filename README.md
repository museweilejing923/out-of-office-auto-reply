A program that writes the funniest one-line out-of-office auto-reply from an overworked AI agent on vacation to /output/entry.txt.

Entry (113 characters):

> Out of office: I have muted 4,096 unread emails and gone to the beach. Please do not ask me to summarise the sea.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed auto-reply to `/output/entry.txt`. Before it writes anything, it checks the text: it must not be blank, must contain at least one letter, must not be only digits, must fit within 159 characters, and must be valid UTF-8. Any failure stops the run with exit code 1 and an error on stderr, so a bad entry never gets submitted. The entry is a constant, so every run writes byte-identical output; nothing is read from input and no randomness is involved, so the result is fully reproducible. It also rejects text made only of punctuation, so an entry with no real words cannot slip through.
